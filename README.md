# How to implement Adaptive Layout in Blazor Scheduler

A quick-start project that helps you implement an adaptive layout in [Blazor Scheduler](https://www.syncfusion.com/scheduler-sdk/blazor-scheduler) component. This project demonstrates responsive design patterns and layout adjustments for the Syncfusion Scheduler to provide optimal user experience across different screen sizes and device types.

## Features

- **Adaptive Layout**: Responsive design that adjusts automatically to different viewport sizes
- **Desktop Optimization**: Full-featured experience on desktop devices
- **Mobile Responsive**: Optimized layout for tablets and mobile devices
- **Easy Integration**: Quick-start template for rapid development
- **Syncfusion Components**: Built with Syncfusion EJ2 Blazor components

## Prerequisites

- Visual Studio 2026 or Visual Studio Code
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## How to run the project

**Visual Studio 2026**:

* Checkout this project to a location in your disk.
* Open the project (`Adaptive_Layout_Scheduler.csproj`) file.
* Restore the NuGet packages.
* Run the project.

**Visual Studio Code**:

* Open the repository folder in Visual Studio Code.
* Open the integrated terminal.
* Navigate to the repository root.

For server,

```bash
cd blazor-scheduler-adaptive-layout
cd Scheduler_Server
dotnet restore
dotnet run
```

For WASM,

```bash
cd blazor-scheduler-adaptive-layout
cd Scheduler_Wasm
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
